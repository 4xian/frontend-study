# Java 全家桶课程规划快照

> 记录日期：2026-08-16  
> 状态：延期讨论，非当前执行路线

## 一、已经确认的规划原则

- 课程采用“知识领域 -> 主题组 -> 单课”三级结构，难度只作为标签。
- 一课对应一项可独立掌握的能力，不能过细，也不能混入多个独立主题。
- JDK 25 为教学主线；只有存在真实差异时才就近说明 Java 8 写法，不涉及 JDK 26。
- 核心语法可以展开得更充分，但只保留后端开发常用能力，不常用知识不进入默认路线。
- 每课正文继续执行 [`java-course-authoring-standard.md`](./java-course-authoring-standard.md)。
- Java 全家桶与 Spring Boot Web 使用独立课程表，不共享一条强制学习路线。
- 旧课程正文、研究资料和候选课可以复用知识详解，但每课仍需按新结构重新编写。

## 二、延期的九大领域方案

| 顺序 | 知识领域 | 目标 | 初步课数 |
| --- | --- | --- | ---: |
| 1 | Java 核心语法 | 能独立编写和调试常用 Java 程序 | 30-35 |
| 2 | 对象与集合 | 能建立业务对象并处理批量数据 | 30-35 |
| 3 | 异常、I/O 与现代 Java | 能处理失败、文件、时间、金额和数据转换 | 20-25 |
| 4 | 工程化与 Web 基础 | 能使用 Maven，并理解 HTTP、REST 和 JSON | 12-15 |
| 5 | Spring Boot Web | 能开发规范的 REST API | 25-30 |
| 6 | MySQL 与数据访问 | 能完成 CRUD、分页、事务和数据库迁移 | 15-18 |
| 7 | Web 进阶与 Redis | 能处理缓存、Session、幂等、并发和外部接口 | 15-18 |
| 8 | 测试与安全 | 能测试接口并实现基础认证授权 | 15-18 |
| 9 | 交付与综合实战 | 能打包部署、观察和排查完整 Web 项目 | 12-15 |

该数量只是延期前的初步估算。恢复讨论时，应根据“开发常用”重新筛选，不为了满足区间强行增加或
删除课程。
