# 前端课程计划目录

本目录按技术保存课程计划。每条课程技术主线可以新增一份计划文档，例如：

```text
plans/react/React-Router课程计划.md
plans/react/Redux-Toolkit与React-Redux课程计划.md
plans/react/Zustand课程计划.md
plans/react/TanStack-Query课程计划.md
```

一个技术模块只维护一份现行课程计划。计划只记录基础、中级、高级、实战等整体课程地图、课程顺序、
学习终点和完成复选框，不拆分逐课计划，不保存调查、验证、审查、signoff 或执行日志。每课完成全部
适用门禁后只勾选对应课程；当前课未完成前不调研或编写下一课。

所有课程先遵守前端通用规范，再遵守对应技术补充规范。尚未确认课程地图的技术不提前创建空计划。
