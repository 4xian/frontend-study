## 1. 课程定位

本模块从零基础进入 React Router，最终达到能够设计、实现、调试和交付生产级客户端路由系统的程度。
课程以本科阶段常用前端开发能力为范围，按基础、中级、高级递进；每个阶段包含 14 节知识课和 2 节
实战课，共 48 课。

Data Mode 是唯一实现主线，已经包含 Declarative Mode 的核心导航与渲染能力。Declarative Mode 只用于
识别已有项目，Framework Mode 只讲能力边界与迁移，不分别建立重复课程路线。React Router API
Reference 在 Redux Toolkit + React Redux、Zustand 和 TanStack Query 课程完成后统一实施。

## 2. 执行规则

- 统一遵守 [`课程内容规范.md`](../../standards/课程内容规范.md)、
  [`调研与来源规范.md`](../../standards/调研与来源规范.md)、
  [`质量门禁规范.md`](../../standards/质量门禁规范.md) 和
  [`React技术补充规范.md`](../../standards/react/React技术补充规范.md)。
- 每次只实施一课。当前课完成前，不调研、编写或登记下一课。
- 本计划不固定 React Router 版本；每课实施时实时核对当时最新稳定版官方资料，再确定该课的详细内容、
  Demo、易错点和边界。
- 属于本课的内容尽量完整覆盖，不限制正文行数或字数；语言直接、准确，不堆叠修饰和重复说明。
- 课程正文和左侧标题只描述本课知识，不出现本计划编号、完成进度、批次或其他课程的实施内容。
- 不保存逐课调研、临时验证、复审、signoff 或执行日志；全部适用门禁通过后只勾选本清单对应课程。
