## 3. 冻结事实与边界

### 3.1 泛型与约束

1. 类型参数可捕获输入类型并在返回位置复用，从而保留输入输出关系；`any` 会丢失这种对应关系
   （[Hello World of Generics](https://github.com/microsoft/TypeScript-Website/blob/c8170c35bda4811c9516cbb69c39241ae4beb6d9/packages/documentation/copy/en/handbook-v2/Type%20Manipulation/Generics.md#hello-world-of-generics)）。
2. 未约束的类型参数必须按“可能是任意类型”使用，不能直接假定存在 `.length`；`Type extends
   Lengthwise` 可声明最低能力，同时返回值仍保留具体 `Type`
   （[Generic Constraints](https://github.com/microsoft/TypeScript-Website/blob/c8170c35bda4811c9516cbb69c39241ae4beb6d9/packages/documentation/copy/en/handbook-v2/Type%20Manipulation/Generics.md#generic-constraints)）。
3. 类型实参通常可由值实参推导；复杂场景无法推导时仍可显式提供
   （[Hello World of Generics](https://github.com/microsoft/TypeScript-Website/blob/c8170c35bda4811c9516cbb69c39241ae4beb6d9/packages/documentation/copy/en/handbook-v2/Type%20Manipulation/Generics.md#hello-world-of-generics)）。
4. 带默认值的类型参数成为可选实参，默认类型仍必须满足已有约束；本课只讲函数、类型别名、约束、
   推导和默认值，不展开泛型类、factory 或 variance annotation
   （[Generic Parameter Defaults](https://github.com/microsoft/TypeScript-Website/blob/c8170c35bda4811c9516cbb69c39241ae4beb6d9/packages/documentation/copy/en/handbook-v2/Type%20Manipulation/Generics.md#generic-parameter-defaults)）。

### 3.2 `keyof`、`typeof` 与索引访问

1. `keyof` 接收对象类型并产生其 string 或 numeric literal 键联合；number 索引签名得到 `number`，
   string 索引签名得到 `string | number`，因为 JavaScript 会把数字属性键转成字符串
   （[`keyof` type operator](https://github.com/microsoft/TypeScript-Website/blob/c8170c35bda4811c9516cbb69c39241ae4beb6d9/packages/documentation/copy/en/handbook-v2/Type%20Manipulation/Keyof%20Type%20Operator.md#the-keyof-type-operator)）。
2. 类型位置的 `typeof` 取得变量或属性的类型；值名称不能直接当作类型传给 `ReturnType`，应写成
   `ReturnType<typeof fn>`
   （[`typeof` type operator](https://github.com/microsoft/TypeScript-Website/blob/c8170c35bda4811c9516cbb69c39241ae4beb6d9/packages/documentation/copy/en/handbook-v2/Type%20Manipulation/Typeof%20Type%20Operator.md#the-typeof-type-operator)）。
3. 类型位置的 `typeof` 只允许标识符或其属性，不执行函数调用等任意表达式
   （[`typeof` limitations](https://github.com/microsoft/TypeScript-Website/blob/c8170c35bda4811c9516cbb69c39241ae4beb6d9/packages/documentation/copy/en/handbook-v2/Type%20Manipulation/Typeof%20Type%20Operator.md#limitations)）。
4. `Type[Key]` 查询属性类型；`Key` 可以是 literal union、`keyof Type` 或类型别名，
   `typeof Items[number]` 可取得数组元素类型。不存在的属性会产生诊断，值变量本身不能直接充当索引类型
   （[Indexed Access Types](https://github.com/microsoft/TypeScript-Website/blob/c8170c35bda4811c9516cbb69c39241ae4beb6d9/packages/documentation/copy/en/handbook-v2/Type%20Manipulation/Indexed%20Access%20Types.md)）。

### 3.3 映射类型

1. 映射类型以 `Property in keyof Type` 遍历键，并用 `Type[Property]` 等表达式系统地产生属性类型
   （[Mapped Types](https://github.com/microsoft/TypeScript-Website/blob/c8170c35bda4811c9516cbb69c39241ae4beb6d9/packages/documentation/copy/en/handbook-v2/Type%20Manipulation/Mapped%20Types.md)）。
2. `readonly` 与 `?` 可在映射时用 `+` 添加或用 `-` 移除；省略前缀等同于 `+`
   （[Mapping Modifiers](https://github.com/microsoft/TypeScript-Website/blob/c8170c35bda4811c9516cbb69c39241ae4beb6d9/packages/documentation/copy/en/handbook-v2/Type%20Manipulation/Mapped%20Types.md#mapping-modifiers)）。
3. `as` 子句可重映射键；新键可以来自模板字面量，也可通过产生 `never` 过滤旧键
   （[Key Remapping via `as`](https://github.com/microsoft/TypeScript-Website/blob/c8170c35bda4811c9516cbb69c39241ae4beb6d9/packages/documentation/copy/en/handbook-v2/Type%20Manipulation/Mapped%20Types.md#key-remapping-via-as)）。
4. 本课只把简单模板字面量作为 `as` 的输入，不展开字符串 intrinsic、组合爆炸或递归映射；模板字面量
   设计留给 T2-2，复杂类型设计留给 T3。

### 3.4 条件类型

1. `SomeType extends OtherType ? TrueType : FalseType` 依据左侧是否可赋给右侧选择分支；与泛型组合时可
   表达输入类型和输出类型的关系
   （[Conditional Types](https://github.com/microsoft/TypeScript-Website/blob/c8170c35bda4811c9516cbb69c39241ae4beb6d9/packages/documentation/copy/en/handbook-v2/Type%20Manipulation/Conditional%20Types.md)）。
2. true 分支会获得检查带来的额外约束，因此可以安全访问检查中已经证明存在的成员
   （[Conditional Type Constraints](https://github.com/microsoft/TypeScript-Website/blob/c8170c35bda4811c9516cbb69c39241ae4beb6d9/packages/documentation/copy/en/handbook-v2/Type%20Manipulation/Conditional%20Types.md#conditional-type-constraints)）。
3. 条件类型作用于裸泛型参数时会对 union 各成员分布；因此 `ToArray<string | number>` 是
   `string[] | number[]`，不是 `(string | number)[]`
   （[Distributive Conditional Types](https://github.com/microsoft/TypeScript-Website/blob/c8170c35bda4811c9516cbb69c39241ae4beb6d9/packages/documentation/copy/en/handbook-v2/Type%20Manipulation/Conditional%20Types.md#distributive-conditional-types)）。
4. 官方还定义了 true 分支中的 `infer`，并用方括号包裹 `extends` 两侧来抑制分布；T2-1 只要求识别
   默认分布，`infer`、主动控制分布和 `never` 消除留给 T3
   （[Inferring Within Conditional Types](https://github.com/microsoft/TypeScript-Website/blob/c8170c35bda4811c9516cbb69c39241ae4beb6d9/packages/documentation/copy/en/handbook-v2/Type%20Manipulation/Conditional%20Types.md#inferring-within-conditional-types)、[Distributive Conditional Types](https://github.com/microsoft/TypeScript-Website/blob/c8170c35bda4811c9516cbb69c39241ae4beb6d9/packages/documentation/copy/en/handbook-v2/Type%20Manipulation/Conditional%20Types.md#distributive-conditional-types)）。

## 4. 最小临时 fixture

| 课程 | positive 必证 | negative 必证 |
| --- | --- | --- |
| 泛型与约束 | `identity<Type>` 保留关系，`Type extends { length: number }` 接受字符串，`Box<Type = string>` 使用默认值 | `withLength(3)` 违反约束，产生 `TS2345` |
| `keyof`、`typeof` 与索引访问 | 从对象值组合 `typeof`、`keyof`、`Type[Key]`，受约束的 `get` 返回准确属性类型 | `User['email']` 查询不存在属性，产生 `TS2339` |
| 映射类型 | `-readonly`、`-?` 生成可写必填类型，`as` 生成 getter 键 | 缺少由 `-?` 变为必填的属性，产生 `TS2741` |
| 条件类型 | 分支可提取已证明的成员类型，裸泛型参数对 `string | number` 分布 | 混合数组赋给分布结果 `string[] | number[]`，产生 `TS2322` |

上述候选已用仓库本地 TypeScript `6.0.3` 隔离验证：四个 positive 均 exit 0，四个 negative 均非零且
分别包含表中的单一核心诊断码。复验时在 `/tmp` 的 `mktemp` 目录创建最小 runner，只断言 exit code
与必要诊断码，不锁定完整诊断文案；fixture 保持纯类型检查、`noEmit`，结束后删除，不创建浏览器 Demo
或第二套 registry。
