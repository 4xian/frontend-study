# IT 学习站前端文档入口

本项目定位为 IT 学习站。本目录只管理其中的前端内容域，包括前端规范、路线计划和覆盖基线。
后端文档由 `docs/backend/` 独立维护，前端任务不得修改、移动或格式化后端文件。

## 权威顺序

发生冲突时，按以下顺序处理：

1. [`IT学习站前端规范.md`](./IT学习站前端规范.md)：前端域稳定的信息架构和内容模块 interface。
2. [`standards/`](./standards/)：课程、Reference、Demo、来源和质量门禁的可执行规范。
3. [`IT学习站前端路线计划.md`](./IT学习站前端路线计划.md)：模块顺序、当前状态和阶段 Gate。
4. [`plans/`](./plans/)：当前模块、当前批次的临时实施与调研文件。
5. [`coverage-matrices/`](./coverage-matrices/)：官方内容范围和站内映射基线。

代码中的 schema、manifest 和测试负责执行文档规则。文档与代码不一致时，先停止内容扩展，
查明是规范过期还是实现偏离，不得静默选择一边。

## 文档生命周期

长期保留规范、总计划和覆盖基线。调研与实施计划只在对应模块或批次执行期间存在；Gate 关闭后，
先把仍有效的规则和最终覆盖数据写入长期文档，再删除已完成的调研与实施计划，并清除所有引用。
Git 历史承担过程追溯，不在当前文档树中保留完成批次的流水账。
